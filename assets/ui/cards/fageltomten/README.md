# FagelTomten playing cards

Source: https://fageltomten.itch.io/
Downloaded original free ZIPs on 2026-10-23. Eight complete packs / 138 original PNGs: geometric, fantasy, fire, art-deco, nautical, forest, space, classic. Classic includes light and dark frames. Original card fronts, pips and backsides are retained.

The game uses the nine original blank card frames and overlays existing animated character portraits and stats. assignments.json records the deterministic balanced shuffle (seed 20261023). Character catalog copies on client/backend contain identical frame paths and 23x35 crops. No combat stats or card-back selections changed.
