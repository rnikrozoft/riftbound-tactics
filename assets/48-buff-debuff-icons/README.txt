48 BUFF & DEBUFF ICONS (FREE)

48 pixel art buff and debuff status effect icons - real pixel grid, no
anti-aliasing, 32x32 and 64x64. Built for a status bar, a buff/debuff
tracker, a spell effects panel, or any RPG that needs a big set of
distinct positive and negative status icons. Free - use it, and if you
like the style check out the rest of the pixel line in the store.

WHAT'S IN THE BOX

png_32/         48 icons at 32 x 32
png_64/         the same at 64 x 64
aseprite/32/    .aseprite source files at 32 x 32
aseprite/64/    .aseprite source files at 64 x 64
atlas/          sprite sheet + coordinates
palette/        shared colour palette swatch
preview/        promo sheets

Every file is a square transparent PNG with the background fully cut.

WHAT'S INSIDE

Buffs               16   stat boosts, regen, shields, haste, blessed
                          aura, resistances, and more positive effects

Debuffs             16   poison, burn, freeze, stun, curses, fear,
                          bleed, disease, and more negative effects

Special Effects     16   more buffs and debuffs - invincibility,
                          reflect, luck, petrify, mind control, and more

Files are named icon01.png through icon48.png - simple sequential IDs,
so you're free to map them to your own status effect system.
